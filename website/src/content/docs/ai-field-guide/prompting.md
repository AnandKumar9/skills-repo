description: Guidance for writing prompts that produce reliable outputs.

Good prompts define the task, the context, the constraints, and the expected output shape.

Use this page for reusable patterns, examples, anti-patterns, and review notes for prompt design.

## Prompt Checklist

- State the goal clearly.
- Include relevant context and exclusions.
- Define the output format.
- Give the model permission to ask for missing critical details.
