The AI Field Guide is a Starlight-driven documentation section inside the larger static site.

Use this area for long-form guides, reference material, and operational notes that benefit from docs navigation, page tables of contents, search, and Markdown-first authoring.

The rest of the site remains a catalog for repository content such as skills and subagents. This section is the companion guide for concepts, patterns, and operating practices that need more room than a card or summary.

## Sections

Start with [Foundations](./foundations/) for the core vocabulary, then move into [Prompting](./prompting/) and [Agents](./agents/) for practical workflows.

Use [Patterns](./patterns/) for reusable implementation approaches, including retrieval and evaluation loops. Use [Operations](./operations/) for release checks, monitoring, and incident notes.

## When to Use This Guide

- Put durable explanations, reference material, and multi-page operational notes here.
- Keep skills, subagents, and other catalog source folders at the repository root.
- Use custom Astro pages for browseable catalog surfaces, filters, cards, and dialogs.
