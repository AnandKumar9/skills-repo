This git repo will have a bunch of folders like skills/, subagents/, etc. it will have different Codex, Windsurf and other markdowns in them. 

There will be one folder named website, this is where all the code related to a static website built using the web framework Astro will need to be. While the config does have Starlight too, use it only when necessary.

Always remember that any of the folders from repo's root skills, subagents, etc. should not be duplicated in a Starlight specific docs folder just for Starlight's needs. Creating other files in that docs folder is fine.
