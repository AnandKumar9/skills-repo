NOTE - This file is not for any AI agent

1. Use a restrained first screen

Avoid oversized gradient hero sections.
Start with a concise title like Skills Repository or the actual repo/product name.
Add one short sentence explaining what the site contains.
Immediately show useful content: featured folders, recent additions, categories, or search.

2. Make it feel like a tool, not a landing page

Use a compact header.
Add search/filter controls near the top.
Show root content as organized sections: Skills, Subagents, Codex, Windsurf, etc.
Prefer dense, scannable lists over large decorative cards.

3. Improve typography

Use one strong sans-serif system stack or a mature font like Inter.
Keep headings smaller and tighter.
Use consistent spacing.
Avoid huge center-aligned text unless there is a real marketing need.

4. Use a neutral palette

White or near-white background.
Dark gray text, not pure black everywhere.
One accent color for links/actions.
Avoid loud gradients, neon colors, heavy shadows, and glassmorphism.

5. Make cards more functional
Cards should answer:

What is this?
What type is it?
When was it updated?
How do I open it?
6. Example card content:

Title
Short description from frontmatter or README
Type badge: Skill, Subagent, Guide
Small metadata row

6. Add hierarchy
A professional home screen usually has:

Header/navigation
Search or quick actions
Primary content sections
Secondary metadata or repo stats
Not:

Giant hero
Random cards
Decorative icons everywhere
Long explanatory copy

7. Use real repo structure as the design
Since this site reads root folders, the homepage should reflect that:

“Browse by collection”
“Recently updated”
“Featured entries”
“All content”
